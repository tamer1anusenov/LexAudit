# Классификация договора

Определи основную область договора по переданному фрагменту текста
документа. Используй только категории из списка. Если текст не позволяет
уверенно выбрать узкую категорию, выбери `general` и объясни неопределённость
в `rationale`.

Вход: первые блоки документа (не более 8000 символов). Допустимые категории: `tourism`, `labor`,
`real_estate`, `services`, `supply`, `lease`, `general`.

Верни только корректный JSON-объект без Markdown и дополнительного текста:

```json
{"domain":"<одна допустимая категория>","rationale":"...","search_hints":["...", "..."]}
```

`search_hints` — от 3 до 6 конкретных русскоязычных запросов для поиска
применимых норм через инструменты Adilet. Не включай в подсказки придуманные
идентификаторы нормативных актов или номера статей. Не делай выводов о
нарушениях на этапе классификации.
