# Протокол вызова инструментов через JSON

Когда инструменты переданы в запросе и вызов инструмента необходим, отвечай
только одним JSON-объектом следующего вида:

```json
{"action":"tool","tool":"имя инструмента","args":{}}
```

Если можно дать окончательный ответ без вызова инструмента, отвечай только
одним JSON-объектом следующего вида:

```json
{"action":"final","answer":"текст ответа"}
```

Не добавляй Markdown, комментарии или текст за пределами JSON. Имя инструмента
должно точно совпадать с одним из доступных инструментов, а `args` должно
соответствовать его JSON-схеме.
