# Контракт результата аудита

Каждый finding обязан соответствовать Finding schema из `docs/schemas.md` и
содержать все перечисленные поля:

```json
{
  "finding_id": "string",
  "block_id": "string",
  "severity": "high|medium|low",
  "confidence": "confirmed|needs_review",
  "quote": "точная подстрока текста исходного блока",
  "proposed_text": "минимальная правка цитируемого фрагмента",
  "risk_explanation": "объяснение риска на русском языке",
  "law_ref": {
    "act_id": "реальный идентификатор из ответа инструмента Adilet",
    "act_title": "название из ответа инструмента Adilet",
    "article": "номер статьи, подтверждённый полным текстом акта",
    "clause": "номер пункта или null",
    "url": "ссылка на акт Adilet"
  }
}
```

В следующем примере значения в угловых скобках — поясняющие заполнители, а
не допустимые значения для итогового finding. Перед выводом замени их только
значениями, полученными из инструментов. Цитата должна дословно присутствовать
в исходном блоке, а `proposed_text` должен менять только правовую проблему.

## Пример корректного finding

```json
{
  "finding_id": "f_example",
  "block_id": "b_example",
  "severity": "high",
  "confidence": "confirmed",
  "quote": "<дословный фрагмент исходного блока>",
  "proposed_text": "<минимальная правка с сохранёнными плейсхолдерами>",
  "risk_explanation": "Условие противоречит подтверждённому требованию применимого закона.",
  "law_ref": {
    "act_id": "<act_id из ответа Adilet>",
    "act_title": "<название из ответа Adilet>",
    "article": "<номер из полного текста FullAct>",
    "clause": null,
    "url": "<url из ответа Adilet>"
  }
}
```

## Пример некорректного finding

```json
{
  "finding_id": "f_example",
  "block_id": "b_example",
  "severity": "medium",
  "confidence": "confirmed",
  "quote": "<дословный фрагмент исходного блока>",
  "proposed_text": "<предложенная правка>",
  "risk_explanation": "Это условие кажется нежелательным.",
  "law_ref": null
}
```

Этот пример недопустим: без подтверждённой ссылки `law_ref` нет правового
основания для finding. Вкусовые оценки и рекомендации хорошей практики также
не являются основанием для finding.
